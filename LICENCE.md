## 🧩 About

**Path of Exile Tool** is a comprehensive overlay and helper utility for Path of Exile featuring live stat overlays, loot filter management, trade macros, timer tracking, and build planner integration.

Based on popular tools like **Awakened PoE Trade**, **Exilence Next**, and **PoE Overlay**.

---

## ✨ Features

### 🎮 Core Tools
- Live Stat Overlay — monitor life, mana, ES, and resistances in real time
- Trade Macro — quick price check and whisper for listed items
- Loot Filter Helper — edit and switch filters without leaving the game
- Timer Tracker — track map, flask, and buff durations
- Build Planner Sync — import and view passive tree notes

### 🎨 UI & Customization
- Theme Switcher — light, dark, and custom color profiles
- Hotkey Editor — rebind every overlay action
- Widget Layout — drag, resize, and pin overlay panels

### 🏋️ Utility & Automation
- Clipboard Parser — parse item text into structured data
- Stash Search Helper — highlight items by affix or tier
- Session Logger — record map runs and loot history
- Auto-Hide Overlay — hide UI during combat or cinematics
